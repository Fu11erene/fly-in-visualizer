# fly-in-visualizer

[English](README.md) | 日本語

Fly-in の出力を、動画プレーヤーのように 1 ターンずつ再生し、ルール違反を
すべて赤で示すツールです。出力が正しいことを見せるために使います。どこにも
赤がなければ、全ターンですべてのルールが守られています。

## 必要なもの

- Python 3.14 と [uv](https://github.com/astral-sh/uv)
- Fly-in のリポジトリ（このツールは Fly-in を実行して出力を得ます）

## 使い方

Fly-in のリポジトリの中にクローンします。Fly-in の `.gitignore`・flake8・
mypy・ruff の設定は、すでに `fly-in-visualizer/` を対象外にしています。

```
cd Fly-in
git clone https://github.com/Fu11erene/fly-in-visualizer.git
cd fly-in-visualizer
make install
make play MAP=../maps/easy/02_simple_fork.txt
```

`make play` は `MAP` で Fly-in を実行し、その出力を `.play-output.txt` に
保存してから再生します。Fly-in がエラーで止まった場合（マップがない、end に
たどり着けない など）は、そのメッセージを表示し、ウィンドウは開きません。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `MAP` | `../maps/easy/01_linear_path.txt` | Fly-in を実行するマップ |
| `FLYIN` | `..` | Fly-in のリポジトリの場所 |
| `PLAY_OUT` | `.play-output.txt` | Fly-in の出力を保存する場所 |

## 操作

| キー | 動作 |
|---|---|
| SPACE | 再生 / 一時停止（最終ターンからは最初に戻って再生） |
| LEFT / RIGHT | 1 ターン戻る / 進む |
| HOME / END | 最初 / 最後のターンへ |
| 1-4 | 速度 0.5x / 1x / 2x / 4x（1x は 1 秒で 1 ターン） |
| マウス | 各ボタン。シークバーのクリック・ドラッグで好きなターンへ |
| Q / ESC | 終了 |

## 画面の見方

**マップ（上）**

- ゾーンは、マップで指定された色の円で、座標どおりに配置します。
  blocked ゾーンには × を描きます。
- 各ゾーンには、そのターンの終わりにいるドローンの数を
  `ドローン数 / max_drones` で表示します。start と end の上限は `nb_drones` です。
- 各接続には、そのターンに使ったドローンの数を
  `ドローン数 / max_link_capacity` で表示します（両方向の合計）。
- そのターンに使われた接続は、オレンジの太線で描きます。
- ドローンは番号入りの白い丸で、ターンの間に接続の上を移動します。
  restricted ゾーンへ向かうドローンは、1 ターンのあいだ接続の中ほどで止まり、
  次のターンに着陸します。
- 同じ場所に 7 機以上が止まっているときは、`xN` と書いた丸ひとつで描きます。
- 混み合ったマップでは、ゾーン名を隠し、使用中の数字だけを表示します。
  ゾーンにマウスを乗せると、名前・使用数・種類を表示します。

**パネル（下）**

- シークバー。現在のターンと、違反のあるターンに赤い目印を表示します。
- 再生と速度のボタン。
- 現在のターンの出力 1 行。Fly-in が出力したとおりの色で表示します。
- 現在のターンの違反。再生全体に違反がなければ `No violations` と表示します。
- キー操作の一覧。

## 違反

数え方は Fly-in の予約表と同じです。ゾーンは、ターンの終わりにそこにいる
ドローンを数えます（待機中も含む）。接続は、そのターンに使ったドローンを
数えます。restricted ゾーンへの進入は、進入したターンだけ接続を使います。
着陸と待機は接続を使いません。

| 破られたルール | 赤く描くもの |
|---|---|
| ゾーンのドローン数が `max_drones` を超えた | ゾーン |
| 接続のドローン数が `max_link_capacity` を超えた | 接続 |
| 接続のないゾーン間を移動した | ドローン |
| blocked ゾーンに入った | ゾーンとドローン |
| restricted ゾーンに 1 ターンで入った | ゾーンとドローン |
| 接続の上にいるドローンが、次のターンに着陸していない | ドローン |
| 接続の上にいるドローンの行き先が restricted ゾーンではない | 接続とドローン |
| 存在しないゾーン名・接続名 | ドローン |
| `1..nb_drones` の範囲外のドローン番号 | （メッセージのみ） |
| 同じ行に同じドローンが 2 回現れた | ドローン |
| end に着いたドローンがまた動いた | ドローン |
| 最終ターンに end にいないドローンがいる | ドローン |

違反があっても再生は続きます。ドローンは出力に書かれた位置に描きます。
出力の名前が存在しない場合は、前の位置に残したまま描きます。

## 開発

```
make test      # pytest
make lint      # flake8 + mypy
make format    # ruff check --fix
make debug     # make play を pdb の下で実行
```

`tests/fixtures/` には、Fly-in の全マップと、それぞれに対する Fly-in の出力が
入っています。テストでは、そのすべてが違反なしで再生できることを確かめて
います。ウィンドウを開かずに描画を確かめるには、次を実行します。

```
SDL_VIDEODRIVER=dummy uv run python -m scripts.snapshot \
    <map_file> <output_file> <turn> <png_file>
```

| ファイル | 役割 |
|---|---|
| `fly_map.py` | マップファイルを読む |
| `replay.py` | Fly-in の出力と、その色を読む |
| `simulation.py` | 各ターンを復元する（位置・使用数・違反） |
| `player.py` | 再生の時間管理（再生・コマ送り・ジャンプ・速度） |
| `layout.py`, `colors.py` | 画面上の位置と色 |
| `view.py` | マップを描く |
| `panel.py` | パネルを描き、ボタンの操作を受け付ける |
| `app.py`, `main.py` | ウィンドウ、メインループ、コマンドライン |
